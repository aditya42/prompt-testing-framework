# Live prompt regression

The existing web/API simulator remains unchanged. The manually dispatched Live prompt regression workflow integrates pinned revisions of llm-evaluation-framework and AI-QE-Eval-500. Add OPENAI_API_KEY under repository Actions secrets, then select Actions > Live prompt regression > Run workflow. Enter current generation model prices in USD per million tokens, prompts, model and distinct judge. Start with five held-out cases. Four API calls per case excluding retries. The JSON artifact contains real responses, rubric judgments, regression verdict, latency, tokens and estimated generation cost. Judge costs are excluded. Reports contain prompts and outputs; use only nonconfidential inputs. This is CI integration, not live web UI integration. A failed quality gate fails the job but retains the report when generated. No automatic paid runs are scheduled.
